# Føyner Studio

The editable Next.js version of the Føyner Studio homepage.

## Open in VS Code

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

The homepage content is in `app/page.tsx`, the design is in `app/globals.css`, and public images/icons go in `public/`.

## Publish changes

```bash
git add .
git commit -m "Update Føyner Studio"
git push
```

Connect the GitHub repository to Vercel for automatic deployments whenever the `main` branch is updated.
